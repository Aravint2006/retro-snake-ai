# Retro Snake AI 🐍

Retro Snake AI is a classic retro-style snake game built with HTML, CSS, and JavaScript.  
It features both manual control and an optional AI mode that helps the snake chase food automatically.  
Styled in a green-on-black terminal-like theme for a nostalgic retro feel.

---

## Features

- Classic Snake gameplay on a 20x20 grid  
- **Manual mode**: Control the snake using arrow keys  
- **AI mode**: Toggle AI to automatically move the snake toward the food  
- Visual alerts for game over (collision with walls or self)  
- Retro terminal-style design (green-on-black, monospace font)  
- Runs directly in any modern web browser  

---

## AI Logic

- The AI uses a **simple greedy algorithm**:  
  - Calculates all possible next moves  
  - Chooses the move that **minimizes distance to food**  
  - Avoids collisions with walls and the snake’s own body  
- AI can be toggled on/off during gameplay

## Run

1. Open `index.html` in any modern browser  
2. **Manual Mode:** Use arrow keys to move the snake  
3. **AI Mode:** Click **“Toggle AI Mode”** button to let AI control the snake  
4. Avoid collisions with walls or the snake’s own body
